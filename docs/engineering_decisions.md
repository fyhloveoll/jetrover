# 工程决策记录(多方案评估与选择)

> 本项目差异化靠工程深度。本文档记录关键技术决策的备选方案、评估维度与取舍依据,
> 每条都有真机实验证据支撑。

## D1. 板子锁死自动恢复:硬件继电器 vs 固件看门狗(2026-07-05)

**问题**:STM32 控制板偶发固件锁死("命令死/遥测活":packet_rx 停止处理、TX/调度器照常),
唯一已证恢复手段 = 人工断主电源。无人值守运行必须自动化恢复。

**方案 A:IWDG 固件看门狗**
- 阶段一(喂狗任务,无 checkin)已实现并烧录过;取证(.map 对比、编译器差异、症状匹配)
  推翻了"看门狗砖板"的初判,但**关键发现:阶段一原理上无法捕获真实锁死模式**——
  只死 packet_rx 时喂狗任务照常运行,IWDG 永不超时。
- 对症需阶段二:packet_rx 接 watchdog_checkin + 主机侧心跳包(防空闲期误复位),
  涉及固件/主机联合设计 + 多轮 Keil 重编 + 拆车 ST-Link 烧录迭代。
- 风险:修改不完全理解的 vendor 固件;用户编译器(AC 5.06u3)≠ 厂家(u6),
  重编产物非出厂二进制,行为差异不可排除。
- 优点:恢复延迟 ~2–5s,嵌入式意义上的"正解"。

**方案 B:硬件继电器/MOSFET(Jetson GPIO 控制板子电源)**
- 覆盖率 100%:复刻唯一已证解药(断电),对任何(含未知)故障模式有效。
- 零固件改动 → 零变砖风险;硬件为几元级模块,一次接线。
- 检测器已具备:board_alive() 相机自证(锁死时 odom/servo_states 全部说谎,
  实测 2026-07-01;相机画面是唯一诚实证人)。
- 恢复延迟 ~30–60s(断电 + 重起全栈),软件全部主机侧、可自由迭代。

**证据更新改变了权重**:运行纪律(单一长命节点跑批 / 动作期间零 CLI 探测 /
指令流 10Hz 限流)使锁死率从"1–2 抓一锁"降至 60+ 循环零锁(2026-06-30 实测),
快速恢复(秒级)的边际价值大幅下降。

**决策:先 B 后 A(可选)。** 继电器为兜底安全网,看门狗降级为延迟优化;
二者互补而非互斥。评估维度权重:覆盖率 > 实施风险 > 迭代成本 > 恢复延迟。

## D2. 抓取偏差调参:真机 vs Gazebo 仿真(2026-06-29)

仿真中深度/标定/位姿皆完美 → 抓取点偏差**在仿真中不存在**,只在现实出现
(深度噪声、边缘失效、手眼误差、臂自重下垂)。**决策:偏差类问题只在真机迭代**;
Gazebo 搁置(其残余价值=导航/逻辑仿真,非偏差标定)。后续 FWD 参数的真机 A-B
对照(0.02 偏远端 / 0.01 偏近端 → 取中 0.015)验证了该路线的效率。

## D3. 语义检测:更大封闭类集 vs 开放词表(2026-07-05)

抓取几何由深度分割负责(物体无关,已 38+ 次真机验证),标签仅服务于语义指名和
未来 LLM 层。LVIS/Detic 等更大封闭类集 = 更重的模型 + 仍是封闭菜单(笔/U盘照样
不在)。**决策:跳过大封闭类集,COCO(yolo11m)做当下融合,开放词表(YOLO-World,
26MB,运行时文字定类)对接 M9 LLM** —— 语言层要什么词,检测器就找什么词。

## D4. 偏航角测量:地面投影模型 vs 图像角(2026-06-30)

理论上更优的"轮廓投影到地面平面 + 扣底座转角"模型,实测反而劣化(底座脉冲→角度
映射假设错误,把正确角度改坏);图像角在 ±40° 实测 68%。**决策:证据优先于模型
优雅性,回退图像角**;投影模型的 γ 项列为待研究。方法论:每个"更正确"的模型
必须带着可一键回退的开关(JR_YAW_MODE)上线。

## D5. 遥测可信度:传感器数据 vs 物理证人(2026-07-01)

锁死状态下 servo_states 回显目标值、odom 积分指令速度(板子纹丝不动却报告
"移动了 0.073m",决定性实验)。**决策:执行确认只信物理证人**(蜂鸣器声/
眼见运动/相机画面变化),据此实现 board_alive() 开机自证,杜绝整轮幻影运行。
